# utpl-semiotica

Lecciones narradas de Semiótica (UTPL) en formato SCORM, una diapositiva a la vez con audio y comprobaciones.

**Prof. Juan Pablo Arrobo Agila, Ph.D. · Universidad Técnica Particular de Loja (UTPL)**

## Contenido

- `index.html` — índice del curso: dieciséis semanas de calendario, con enlace a cada lección narrada a medida que se va construyendo.

## Cómo se agrega una semana

1. Se comparte el PowerPoint de esa semana.
2. Se redacta y aprueba el guion de narración.
3. Se genera el audio con la voz Brian C (ElevenLabs).
4. Se construyen los subtítulos sincronizados.
5. Se empaqueta como lección SCORM 2004 y se publica.

Cada lección queda disponible en dos formatos: una vista para repasar en el navegador y un paquete SCORM para subir al EVA de la universidad.

## Publicar con GitHub Pages

Para que `index.html` se sirva como página web pública:

1. En este repositorio, ve a **Settings → Pages**.
2. En **Source**, elige la rama `main` y la carpeta `/ (root)`.
3. Guarda. La página quedará disponible en `https://juanp4105.github.io/utpl-semiotica/` (puede tardar uno o dos minutos en activarse tras el primer guardado).
